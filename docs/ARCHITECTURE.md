# ClipForge — Architecture

## v0.2 redesign: Claude-driven engine (implemented)

After studying two reference videos (see `REFERENCE_VIDEOS.md`), ClipForge was redesigned around one idea: **Claude
is the editor, the engine renders.** The engine lives in `engine/` and runs today on macOS and Linux:

| Layer | Implementation |
|---|---|
| Edit model | `commands.py`: ~35 validated, undoable ops over `edit.json`; the only way state changes |
| Claude, subscription path | `mcp_server.py`: MCP tools for Claude Desktop / Code, plus the `clipforge-editor` skill |
| Claude, API path | `planner.py`: `messages.parse` with a Pydantic plan schema, server-side refusal fallbacks; proposals are accepted per change in the Studio |
| UI | `server.py` + `static/studio.html`: local Studio (Cut → Style → Sound → Finish, Ask Claude) |
| Render | `render.py`: one ffmpeg pass (trims, reframe, camera, B-roll, grade, effects, pop-ups, Pillow motion-graphic sequences, libass captions; voice + ducked music + SFX, loudnorm) |
| Intelligence | `autocut`, `popups` (+ OpenCV faces), `broll`, `recipes` (pacing, pre-flight), `audio_gen` (music + SFX) |

The native SwiftUI app described below remains the long-term shell. It will call the same engine (CLI or MCP)
instead of re-implementing it, so the plan below is kept for reference.

## 1. Principles
1. **One contract.** `TimelineDocument` (the EDL) is read and written by the UI, templates, AI agent, CLI and MCP. LLMs emit **typed commands**, never code.
2. **Local-first.** Every feature has an offline path. Cloud is an optional provider behind the same protocol.
3. **Never block the main actor.** Heavy work runs in actors / `TaskGroup`s with progress (`AsyncStream<JobProgress>`) and cancellation.
4. **Cache by content hash.** Analysis stages are keyed by `(mediaHash, stage, stageVersion, params)`, so nothing re-runs unless its inputs changed.
5. **Explainability.** Every AI decision (score, cut, B-roll pick) carries `reasons: [String]` and a provider stamp.

## 2. Targets & stack
- Swift 6 (strict concurrency), SwiftUI + AppKit bridges, macOS 15+ on Apple Silicon. macOS 26 features (SpeechAnalyzer, Foundation Models) are enabled behind `#available` checks.
- AVFoundation + custom `AVVideoCompositing` (Metal) for preview/export, VideoToolbox for encoding.
- GRDB/SQLite for library and analysis cache. Projects are `.clipforge` packages.
- Project generated by XcodeGen (`project.yml`). Dependencies via SPM.

### 5.1 Edit commands
All mutations go through `EditCommand` (Codable, `apply`/`invert` for undo):

`InsertClip`, `RemoveClip`, `Cut(at)`, `Trim(edge, to)`, `Ripple`, `Slip`, `Slide`, `Move`, `SetSpeed`,
`SetReframe`, `AddTransformKeyframe`, `ApplyEffect`, `ApplyTransition`, `SetColor`,
`SetCaptionStyle`, `EditCaptionWord`, `SetEmphasis`, `InsertBroll`, `SetMusic`, `AddSFX`,
`SetCanvas`, `ApplyTemplate`, `ApplyStyleProfile`, `SetHookVariant`, `AddMarker`, `Batch([EditCommand])`.

AI output is validated against `schemas/commands.v1.json`. On failure, the validator errors are fed back to the model up to 2 times, and then the run fails with a clear message.

## 6. Provider layer

```swift
public enum RoutingMode: String, Codable, Sendable { case offlineOnly, preferLocal, preferCloud, bestQuality }

public protocol Provider: Sendable {
    var id: ProviderID { get }          // e.g. "local.mlx", "cloud.anthropic"
    var isLocal: Bool { get }
    func estimateCost(_ job: JobDescriptor) async -> CostEstimate?
}

public protocol LLMProvider: Provider {
    func complete(_ req: LLMRequest) async throws -> LLMResponse
    func structured<T: Decodable & Sendable>(_ req: LLMRequest, schema: JSONSchema, as: T.Type) async throws -> T
    func runTools(_ req: LLMRequest, tools: [ToolSpec],
                  handler: @Sendable (ToolCall) async throws -> ToolResult) async throws -> LLMResponse
}
public protocol TranscriptionProvider: Provider {
    func transcribe(_ audio: URL, language: String?, progress: ProgressSink) async throws -> Transcript // word-level
}
public protocol DiarizationProvider: Provider { func diarize(_ audio: URL) async throws -> [SpeakerTurn] }
public protocol VisionProvider: Provider {
    func describe(frames: [CGImage], prompt: String) async throws -> String
    func matchBroll(query: String, candidates: [AssetRef]) async throws -> [RankedAsset]
}
public protocol ImageGenProvider: Provider { func generate(_ p: ImagePrompt) async throws -> [CGImage] }
public protocol VideoGenProvider: Provider { func generate(_ p: VideoPrompt) async throws -> URL }
public protocol MusicProvider: Provider {
    func search(_ q: MusicQuery) async throws -> [AssetRef]
    func generate(_ p: MusicPrompt) async throws -> AssetRef
}
public protocol TTSProvider: Provider { func speak(_ text: String, voice: VoiceID) async throws -> URL }
public protocol StockMediaProvider: Provider { func search(_ q: StockQuery) async throws -> [AssetRef] }
public protocol AnalyticsProvider: Provider { func fetch(channel: ChannelRef, since: Date) async throws -> [PostMetrics] }
public protocol PublishProvider: Provider { func publish(_ file: URL, meta: PostMeta, at: Date?) async throws -> PostRef }

public actor ProviderRouter {
    func llm(for task: AITask) throws -> any LLMProvider   // honours RoutingMode + AirplaneMode
    // … one accessor per capability
}
```

- **AirplaneMode** is enforced in `ProviderRouter` *and* in a `URLProtocol` guard, so a stray network call fails in tests.
- **Local adapters:** Apple Foundation Models, MLX Swift, Ollama/LM Studio (HTTP on localhost), WhisperKit, SpeechAnalyzer (macOS 26), Vision, Core ML diffusion.
- **Cloud adapters:** Anthropic Messages API (tool use + vision, prompt caching for transcripts; models configurable, defaults `claude-sonnet-5-5` for planning, `claude-haiku-5-5` for tagging, `claude-opus-5-5` for Style DNA), generic OpenAI-compatible, Pexels/Pixabay.
- Every job writes a `JobRecord` (provider, local/cloud, duration, tokens, cost) shown in the Jobs panel.

## 7. Scoring internals (signature features)

| Component | Inputs | Output |
|---|---|---|
| `FactorScorer` | transcript window, audio RMS/pitch, laughter, motion, faces, shot changes | `Factors{hook, payoff, energy, visual, pacing, context}` each 0–1 |
| `ContextGuard` | candidate span, ±60 s transcript | `completeness` 0–1, `missingSetup: Range?`, fix suggestions |
| `RetentionForecast` | per-second features of the draft | predicted retention curve plus `deadZones` with fixes. v1 is a heuristic; ML later |
| `LoopFinder` | last 5 s vs first 3 s (text similarity + frame similarity) | ranked loop points |
| `TasteLoop` | Triage decisions + imported metrics | per-channel factor weights (regularised logistic/linear model, on-device) |

`score = 100 · σ(Σ wᵢ·factorᵢ + b)`, where `w` starts at a global prior and is personalised by the TasteLoop.

## 8. Persistence
- `Library.sqlite` (GRDB): assets, analysis stage records, moments, triage decisions, metrics, jobs.
- `MyEpisode.clipforge/` package: `timeline.json`, `drafts/*.json`, `analysis/` (symlink or copy of the cache), `assets/`, `history/` (versioned snapshots).
- Crash-safe autosave: write a temp file, `fsync`, then atomically rename, every 10 s and on each command batch.

## 9. Testing strategy
- Unit: command apply/invert round-trips (property tests), schema validation, router policy, airplane guard.
- Golden frames: render fixed frames from fixture videos (generated by `scripts/make-fixtures.sh` with FFmpeg test sources) and compare with a tolerance (SSIM ≥ 0.98).
- AI: recorded fixtures for valid, invalid, and repaired outputs. No live network in CI.
- UI: snapshot tests for main screens in light/dark.
